# Графический проект Lazarus LCL

Откройте эту папку как отдельный проект Zed Delphi. Нужны FPC, Lazarus с LCL,
`lazbuild` в `PATH` редактора и CodeLLDB. На macOS используется Cocoa, на Linux —
GTK2. Настройка инструментов описана отдельно для [macOS](../../macos/lazarus.md)
и [Linux/Astra](../../linux/lcl-acceptance.md). В `.zed/tasks.json` и `.zed/debug.json` есть отдельные задачи двух платформ.

1. Выполните задачу **Lazarus: собрать LCL (macOS)** или **Lazarus: собрать LCL (Linux)**.
2. Выполните **Lazarus: запустить LCL**. Кнопка **Calculate 20 + 22** меняет надпись
   `Ready` на `Result: 42`. Кнопка **Close** закрывает приложение.
3. Для отладки поставьте точку останова в `MainForm.pas` на строке с комментарием
   `LCL_BREAKPOINT` и запустите профиль своей платформы. Нажмите кнопку расчёта.
   В локальных переменных должны быть `LeftValue = 20` и `RightValue = 22`.
   Шаг через строку вычисления даёт `TotalValue = 42`; продолжение обновляет надпись.

Форма хранится в настоящем `.lfm`, проект — в `.lpi`; их можно открыть и в Lazarus.
Конструктора форм в Zed нет. Этот пример не требует сторонних пакетов Lazarus.
Виджеты используют короткие английские подписи для одинаковой проверки на двух
платформах; задачи и эта инструкция написаны по-русски.

Параметр `--smoke-test` предназначен только для автоматической проверки: после
показа формы таймер нажимает настоящую кнопку через `Click`, затем закрывает окно.
Обычный запуск ждёт действий пользователя. Автоматическая DAP-проверка не заменяет
отдельную проверку видимого окна и физического нажатия кнопки.
