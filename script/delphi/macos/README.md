# Локальный пакет Zed Delphi для macOS ARM64

`package.py` упаковывает **уже собранный** нативный исполняемый файл из артефакта
`delphi-macos-arm64-native` workflow `delphi-fork.yml`. Скрипт не запускает Cargo,
не устанавливает приложение и не запускает редактор.

После распаковки `zed-delphi-macos-arm64-native.tar.gz`:

```sh
python3 script/delphi/macos/package.py \
  --source-dir /path/to/extracted/zed-delphi \
  --output '/path/to/output/Zed Delphi.app'
```

Родительская папка результата должна существовать. Существующий `.app`, файл или
символическая ссылка по пути результата не перезаписываются. При ошибке удаляется
только новый пакет, созданный этим запуском.

Проверяются SHA256 исходного файла, provenance и лицензий по `SHA256SUMS`, платформа
`macos-arm64`, настоящий Mach-O и архитектура `arm64` через `file` и `lipo`.
`otool -L` должен показать только библиотеки `/usr/lib/` и `/System/Library/`.
При несистемных зависимостях упаковка останавливается: такие библиотеки скрипт
не переносит и переносимость не заявляет. Минимальная версия macOS берётся из
команд загрузки самого Mach-O, а не из версии компьютера, выполняющего упаковку.
Контрольные суммы проверяют целостность; доверенный источник CI-артефакта следует
проверить отдельно.

В пакете находятся:

- `Contents/MacOS/zed` — нативный файл редактора;
- `Contents/Info.plist` — имя **Zed Delphi**, версия **1.0.1**, идентификатор
  **dev.zed.Zed-Delphi**;
- значки приложения и документов из ресурсов upstream;
- upstream-описания типов документов и разрешений, с русскими пояснениями;
- лицензии GPL/Apache, уведомления зависимостей, исходный `provenance.json`,
  `SOURCE-SHA256SUMS` и отчёт `packaging.json`.

Поддержка документов объявлена с рангом `Alternate`. Обработчики URL, включая
`zed://`, не регистрируются. Скрипт не меняет глобальные ассоциации файлов.

Пакет получает локальную **ad-hoc** подпись через `codesign`, затем проверяется
`codesign --verify --deep --strict`. Это не подпись Developer ID и не нотариальное
заверение Apple. Сохранённые контрольные суммы относятся к исходному артефакту:
подписание изменяет исполняемый файл внутри `.app`.

Скрипт требует macOS и доступных `file`, `lipo`, `otool`, `sips`, `iconutil`,
`codesign`. Результат упаковки ещё не подтверждает запуск интерфейса или работу
сборки и отладки проектов. FPC, pasls и отладчик устанавливаются отдельно.
Для проверки редактора используйте отдельный каталог данных:

```sh
'/path/to/output/Zed Delphi.app/Contents/MacOS/zed' \
  --user-data-dir '/path/to/isolated-zed-delphi-data'
```
