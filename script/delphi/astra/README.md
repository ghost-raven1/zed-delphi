# Free Pascal 3.2.2 для Astra Linux 1.8 x86_64

Рецепт собирает свободный Free Pascal, RTL и пакеты с поддержкой режима Delphi. Это не компилятор Embarcadero: VCL, FireMonkey и совместимость всех проектов Delphi не предоставляются.

Сборка требует Linux x86_64 (возможна эмуляция контейнера), GNU make, GCC, binutils, файлы разработки libc, Python 3, coreutils, tar, gzip, file и исходный компилятор FPC для самосборки. Для Debian 12 зависимости: `apt-get install build-essential fp-compiler python3 file`. Для Astra используйте разрешённые репозитории вашей установки. Исходный архив должен быть заранее получен с [официального сервера FPC](https://downloads.freepascal.org/fpc/dist/3.2.2/source/fpc-3.2.2.source.tar.gz); SHA256 закреплён в скрипте.

```sh
bash /repo/script/delphi/astra/build.sh \
  --source /input/fpc-3.2.2.source.tar.gz \
  --work-dir /build \
  --output-dir /out \
  --jobs 2 \
  --allow-same-version-bootstrap
```

`/build` должен быть пустым, без пробелов в пути; `/out` — отдельной папкой. Данные существующей сборки не удаляются. Официальные версии исходного компилятора в Makefile: 3.0.4 и 3.2.0. Флаг выше явно разрешает установленный FPC 3.2.2 через предусмотренный исходным проектом `OVERRIDEVERSIONCHECK=1`. Другие версии отклоняются. Предварительная проверка требует 4 GiB свободного места для работы и 1 GiB для результата; при общем разделе рекомендуется минимум 6 GiB. Это консервативный бюджет, не измеренный пик сборки. Два задания требуют ориентировочно 3 GiB RAM в контейнере.

Результаты: `fpc-3.2.2-linux-x86_64.tar.gz`, исходный архив, `SHA256SUMS`, журнал и `provenance.json`. Пакет содержит лицензии, рецепт, хеши файлов, сведения об ОС и исходном компиляторе. Переменная `BUILD_IMAGE_REFERENCE` позволяет записать идентификатор содержимого образа контейнера. При сборке на Debian результат остаётся кандидатом для Astra: приёмка на реальной Astra отдельно обязательна. Рецепт нормализует метаданные tar, но не заявляет побитовую воспроизводимость компилятора.

```sh
sha256sum -c SHA256SUMS
sudo tar -xzf fpc-3.2.2-linux-x86_64.tar.gz -C /
/opt/zed-delphi/fpc/3.2.2/bin/fpc -Mdelphi hello.pas
```

Можно распаковать архив в другую папку: скрипт запуска находит компилятор, модули и конфигурацию относительно себя. Он изолирует конфигурацию от системного `fpc.cfg`. Для линковки программ нужны GCC, binutils и файлы разработки libc на целевой системе; системные библиотеки не включены. Перед упаковкой рецепт компилирует и запускает тест с классом, свойством, обобщёнными типами и JSON в режиме Delphi, затем повторяет его после переноса установки в путь с пробелами. Полную совместимость с Astra, отладку и графические библиотеки проверяйте отдельно на целевой машине.
