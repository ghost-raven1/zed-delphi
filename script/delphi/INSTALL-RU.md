# Единая установка и окружения сборки

Установщик выбирает нативный пакет **Zed Delphi 1.0.1** для macOS ARM64,
Linux x86_64 или Linux ARM64. Нужен Python 3.9+. Контрольные суммы закреплены
в исходниках установщика; пакет скачивается с GitHub и проверяется до распаковки.
В macOS дополнительно проверяется подпись приложения. Существующая установка
никогда не заменяется: для обновления выберите новую папку и сохраните старую
до проверки. Пользовательские настройки не изменяются.

Из корня репозитория:

```sh
# macOS ARM64
python3 script/delphi/install.py --destination "$HOME/Applications/Zed Delphi.app"

# Linux x86_64 / ARM64
python3 script/delphi/install.py --destination "$HOME/.local/share/zed-delphi/releases/1.0.1"

# Без сети: заранее скачанный архив из релиза, без переименования
python3 script/delphi/install.py --assets-dir /path/to/release-assets \
  --destination /path/to/new-installation
```

На macOS путь назначения должен оканчиваться на `.app`, включая офлайн-установку.
Установщик выводит массив аргументов `launch` для запуска; приложение автоматически
не открывается. На Linux передайте указанный `--user-data-dir`, чтобы использовать
отдельный каталог данных форка. В macOS изоляцию уже обеспечивает launcher.
Установка не добавляет приложение в PATH и не меняет ассоциации файлов.

Пакет Linux собран на Ubuntu 24.04. Это **не подтверждённый пакет редактора для
Astra**: совместимость glibc, графического стека и интерфейса нужно проверять
на целевой системе. Проверки Lazarus LCL на Astra UBI 1.8 относятся к отдельному
примеру, а не ко всему редактору. Пакет Mac имеет ad-hoc подпись, без Developer ID
и нотариального заверения Apple. Готового пакета Windows или Mac Intel в этом
установщике нет; для них он завершится с объяснением без загрузки чужой архитектуры.

## Проверка окружения

```sh
python3 script/delphi/environment.py doctor
python3 script/delphi/environment.py doctor --json
```

Диагностика показывает ОС, процессор и найденные FPC, Lazarus, pasls, CodeLLDB,
а также инструменты Delphi 10.3 на Windows. Наличие файла не означает успешной
сборки, работоспособности лицензии или совместимости проекта. Компиляторы,
исходники библиотек и отладчики не входят в архив редактора.

Для FPC/Lazarus используйте [настройку Cocoa](macos/lazarus.md),
[пример LCL](examples/lcl_demo/README.md) и [настройку pasls](PASLS.md).
Исправление LFM в pasls пока проверено отдельно на Mac; опубликованный Linux pasls
этого патча не содержит.

## Delphi 10.3 Rio из другой ОС

Для настоящего компилятора Embarcadero требуется отдельная Windows-машина или
виртуальная машина с вашей установленной Delphi 10.3, SDK и компонентами проекта.
Из Zed на Mac/Linux сборка передаётся по SSH; исходники должны быть синхронизированы
между машинами. Существующие `build.py`, `dap_remote.py` и `lsp_remote.py` описаны
в [руководстве Delphi](../../docs/src/languages/delphi.md).

`build.py --tool delphi --msbuild-target Rebuild` поддерживает также `Build`,
`Clean` и `Deploy`. По умолчанию выполняется `Build`. `Clean` и `Deploy` нельзя
совмещать с `--run`, чтобы не запустить старый исполняемый файл.

Установщик не создаёт Windows VM, не устанавливает коммерческий компилятор и
не включает его лицензию. Это первый рабочий этап единого комплекта, а не
универсальный образ RAD Studio. Реальная приёмка Rio, Code Insight 10.3,
визуальный дизайнер DFM/FMX и автоматическая подготовка Windows-окружения остаются
[открытыми задачами](DELPHI-10.3-RU.md).
